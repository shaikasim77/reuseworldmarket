# Reuseworldmarket

Create a website called "Reuse World". Use green and white colors.

It needs:

1. Home page with heading "Reuse World – Waste kadhu, Avakasam!" 

   and two buttons: "Post an Item" and "Browse Items"

2. A page to post an item: item name, photo upload, description, 

   location, category (furniture, clothes, electronics, books)

3. A page showing all items in a grid with photos

4. Login and Signup pages
